# Fotbollsstatistik_DE_Projekt

Det här projektet har handlat om att tvätta, analysera och visualisera fotbollsstatistik i en interaktiv dashboard.


## Power BI dashboard:
https://app.powerbi.com/links/IvJvsP3h6z?ctid=735058e3-0e46-46ce-a1d5-c0b0a68980db&pbi_source=linkShare

## Projektets innehåll:
Rapporten fokuserar på spelardata och innehåller visualiseringar kring:
* Totalt antal spelare och mål.
* Spelfördelning per position (anfallare, mittfältare, försvarare, målvakter).
* Målsnitt baserat på spelarnas ålder.
* Totalt antal mål per lag med tillhörande sökfilter för både ett specifikt lag samt position.


# Vad som används under projektet:
* Python / Pandas för datatvätt och förberedelse av csv filen.
* Power BI för modellering, design och deployment.
